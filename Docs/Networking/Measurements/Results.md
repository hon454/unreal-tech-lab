# 실제 측정 결과

출처: Unreal Insights GameThread CPU 이벤트/타이머 통계, 엔진 UNetConnection 송신 누계.

GT active는 FEngineLoop::Tick에서 계측된 idle 및 명시적 RHI wait 구간의 합집합을 뺀 시간이다. OS 스케줄러 CPU 시간은 아니며 미계측 대기나 선점이 포함될 수 있다.

송신량은 엔진 PacketBytes(송신 버퍼 + 엔진 PacketOverhead) 누계다. 애플리케이션 payload 또는 NIC에서 캡처한 실제 wire bytes와 다르다.

p95는 구간 안에 완전히 들어온 프레임의 nearest-rank 값. scope 부모/자식 시간은 합산하지 않는다.
